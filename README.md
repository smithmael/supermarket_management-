# 🛒 Supermarket Management System (POS)

A modern, full-stack Point of Sale (POS) and inventory management application designed for small to medium-sized supermarkets. This system provides a streamlined interface for cashiers to process sales and a powerful dashboard for administrators to manage stock, categories, and users.

## 🚀 Key Features

*   **Role-Based Authentication:** Secure login system with dedicated interfaces for Administrators and Cashiers.
*   **Inventory Management:** Full CRUD operations for products, including SKU tracking, category assignment, and real-time stock levels.
*   **Point of Sale (POS):** Intuitive checkout interface for cashiers with automated stock decrementing and transaction logging.
*   **Sales Analytics:** Visual dashboard featuring sales trends, daily statistics, and detailed transaction history using interactive charts.
*   **Category Management:** Organize products into custom categories for better inventory structure.
*   **Responsive Design:** A "crafted" UI built with Tailwind CSS, featuring smooth animations and a professional aesthetic.

## 🛠️ Tech Stack

- **Frontend:** React 19, Tailwind CSS, Lucide React (Icons), Motion (Animations), Recharts (Data Visualization).
- **Backend:** Node.js, Express.
- **Database:** SQLite with Prisma ORM for type-safe database queries and migrations.
- **Security:** JWT (JSON Web Tokens) for session management and Bcrypt for password hashing.
